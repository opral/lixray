# Get started with LixRay

1. Open [LixRay](https://lixray.com/) and create a repository.
2. Add a file in the browser. You can put code, documents, media, and other file formats in the same repository.
3. To work with an agent, add `https://lixray.com/mcp` as an MCP server in your client and sign in. See the [MCP guide](./mcp.md) for the available tools.
4. Review changes in the repository. Lix records changes to files and application tables in one history.

To store application data, use Lix's SQL tables. The [internal app guide](./internal-apps.md) shows a small task tracker built on a repository.
