# Get started with LixRay

1. Open [LixRay](https://lixray.com/) and create a repository.
2. Add files in the browser. Documents, spreadsheets, PDFs, images, and other
   formats can live in the same repository.
3. Connect an agent. Add `https://lixray.com/mcp` as a remote MCP server in
   Claude, ChatGPT, Codex, or any MCP client and sign in. See
   [Connect a client](./mcp.md#connect-a-client).
4. Ask the agent to work on your files. Every change shows up in the
   repository's history with who made it. Undo it or restore any earlier
   version.

To store structured data, use Lix's SQL tables. The
[internal app guide](./internal-apps.md) shows a small task tracker built on a
repository.
